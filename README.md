A colossal ocean wave curls into a ring around the setting sun, its crest a
roaring water dragon with a glowing eye — and at the bottom of the ring, a
tiny red-sailed boat with one sailor rides the inner wall, about to be
swallowed. One frozen moment of speed, scale and danger, painted to hit the
AI judge in a single look: the dragon's roar, the blazing sun, the little
red boat that refuses to turn back.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (1024×1024 JPEG, 370,241 bytes) to
`/output/entry.png`. Standard library only, no network, deterministic:
both runs write the same bytes.
